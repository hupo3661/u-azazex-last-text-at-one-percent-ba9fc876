# Last Text at One Percent

The last text a phone sends at one percent battery, 113 characters, in the
phone's own voice:

> i saw everything — the 3am searches, your ex's profile, the 47 alarms you snooze. i'm taking it all to the grave.

## What it is

A dying phone with a secret. It has spent its whole life watching — the 3am
searches, the ex's profile, every snoozed alarm — and instead of a goodbye,
it spends its last percent on a threat: everything it knows goes to the grave
with it. No battery pun, no charger joke, just a confidant turning on its
owner at the last second.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it.
